Welcome to UrTask Bot! 🚀

UrTask is an automated tool that bridges Trello and Telegram, providing daily summaries of your Trello activities.

Getting Started 🔧

  1. Set up your Trello configuration using the /setconfig command.
  2. Use the following format:
    /setconfig your_board_id-your_api_key-your_api_token
  3. Find your Trello API key and token at: https://trello.com/app-key

Important:

Your Trello board must have three lists named exactly:

  • ToDo
  • Doing
  • Done

UrTask will use these lists to generate your daily reports.

How UrTask Creates Reports 📊

UrTask Bot creates daily reports through a sophisticated process:

  1. Scheduled Execution: The bot runs a cron job at 4:50 PM (GMT+7) on weekdays.
  2. Retrieving Configurations: It fetches all user Trello configurations from the MongoDB database.
  3. Processing Each Configuration:
    • Verifies the existence of 'ToDo', 'Doing', and 'Done' lists on the Trello board.
    • Retrieves all cards from the board.
    • Maps cards to their respective lists.
  4. Identifying New Completed Tasks:
    • Checks the 'Done' list for new cards.
    • Compares with previously reported tasks in the database.
  5. Generating the Report:
    • Lists newly completed tasks (cards moved to 'Done' since the last report).
    • Lists current tasks (cards in the 'Doing' list).
  6. Sending the Report: If there are changes to report, the bot sends a message via Telegram to the user.
  7. Updating the Database: Marks newly completed tasks as reported to avoid duplication in future reports.

Additional Features 🌟

UrTask Bot also includes:

  • Morning Reminders: Sent at 9:15 AM (GMT+7) on weekdays to help you plan your day.
  • Evening Reminders: Sent at 5:00 PM (GMT+7) on weekdays to prompt you to update your Trello board.
  • Interactive Commands: Including /start, /help, /setconfig, and /testconfig for easy management of your UrTask setup.
  • Error Logging: Any issues encountered during report generation are logged for troubleshooting.
  • User Interaction Logging: All user commands are logged to help improve the bot's functionality.

Use /help to see all available commands.
